# Proyecto Web - Página para empresa
Este repositorio contiene una página web desarrollada para una empresa dedicada a las soluciones integrales.


# Sitio web en vivo
La página actualmente ya se encuentra publicada, puedes acceder mediante este enlace:
https://paginawebhernan-production.up.railway.app


# Características de la página
- Diseño responsive adaptado a móvil y PC
- Interfaz limpia
- Código ordenado y sencillo de entender


# Tecnologías usadas
- HTML5
- CSS3
- JavaScript
- Node.js

# Instalación y ejecución local

Si deseas ejecutar este proyecto en tu computadora:

1. Clona el repositorio:
git clone https://github.com/Andre1924/PaginaWebHernan

2. Entra en la carpeta del proyecto:
cd PaginaWebHernan

3. Instala las dependencias:
npm install

4.Ejecuta el servidor:
npm start
